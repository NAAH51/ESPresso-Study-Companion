# ESPresso Study Companion

A SquareLine-editable Pomodoro study timer and habit tracker for the LCDWiki 2.8-inch ESP32-S3 touch display.

- **Install guide:** [INSTALL.md](INSTALL.md)
- **Arduino sketch:** `ESPresso/ESPresso.ino` (included in the source package)
- **UI editor:** SquareLine Studio 1.6.2, LVGL 8, 240 x 320

The UI uses a consistent type scale: 16 px headings, 12 px content and buttons, and a large 44 px timer. See the install guide for board settings, dependencies, upload steps, and SquareLine editing notes.
